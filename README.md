# Yunth 楽天スーパーSALE会場

Yunth(美容液ブランド)の楽天スーパーSALE特設会場ページです。

## 開催内容

- **楽天スーパーSALE本編**: 9月4日(金)20:00〜9月11日(金)1:59、Yunth各種美容液が20%OFFクーポン+ポイント10倍
- **3日限定企画**: 9月3日(木)10:00〜23:59限定、美容液に特別セットを先着5,300名様にプレゼント

## ファイル構成

```
index.html          … ページ本体(HTML+CSS+JS、すべてこの1ファイルに含まれています)
images/
  logo.png           … Yunthロゴ
  hero/yunthss-fv.jpg … FV告知画像(コピー・価格・特典すべてを含む1枚)
```

## 現在の実装内容

- **FV**: 提供いただいた告知画像を全幅表示。画像内に焼き込まれている「クーポン獲得はこちら」ボタンの上に、実際にクリックできるリンクを透明で重ねています。
- **タイマー**: FV直下に、3日限定企画(9/3 23:59まで)のカウントダウンを表示。終了後は「3日限定企画終了」の表示に切り替わり、本編クーポン(9/11まで有効)のリンクは無効化しません。
- **紙吹雪演出**: FV画像の上に、ページ読み込み時+数秒おきに紙吹雪がバーストする演出(澤井珈琲キャンペーンLPと同じ実装)。

## ご対応・ご確認いただきたい項目

### 1. クーポン取得URLの設定(必須)

`index.html` 内の `<script>` タグ内、`COUPON_URL` を実際の取得URLに差し替えてください。

```js
const COUPON_URL = "#"; // ← ここを実際のクーポン取得URLに
```

### 2. タイマーの終了日時

```js
const CHANCE_END = new Date("2026-09-03T23:59:59+09:00");
```

## 実装上のご注意

- JavaScriptを使用しています(カウントダウン・クーポンURL一括設定・紙吹雪演出)。JavaScriptが実行できない環境には設置できませんのでご留意ください。
- スマホ表示を基準に作成しており、768px以上でPC向けに幅が広がります。
- Google Fonts(Zen Kaku Gothic New / Josefin Sans)を外部読み込みしています。
