# Yunth 楽天スーパーSALE会場

Yunth(美容液ブランド)の楽天スーパーSALE特設会場ページです。

## 開催内容

- **楽天スーパーSALE本編**: 9月4日(金)20:00〜9月11日(金)1:59、Yunth各種美容液が20%OFFクーポン+ポイント10倍
- **3日限定企画**: 9月3日(木)10:00〜23:59限定、美容液に特別セットを先着5,300名様にプレゼント
- **横長カード3点の割引**: 9月3日(木)10:00〜9月11日(金)1:59、美顔器Deep Boostが24%OFFクーポン、飲むビタミンC/クッションファンデーションがスーパーDEAL(50%/20%ポイント還元)

## ファイル構成

```
index.html            … ページ本体(現在の公開版。横長カードは「飲むビタミンC」「クッションファンデーション」の2枚のみ)
index_full.html        … 横長カード3点(美顔器Deep Boost/飲むビタミンC/クッションファンデーション)すべてありのフル版
images/
  logo.png             … Yunthロゴ
  hero/yunthss-fv.jpg  … FV告知画像
  banner/yunth-sale-925-905.jpg … 定番アイテム上部のセールバナー
  product/             … 美容液2点・定番アイテム12点・横長カード3点、計17点の商品画像
README.md
```

`index.html`(または`index_full.html`)を、`images/`フォルダごと丸ごとアップロードしてください。パスはすべて相対パスです。

## 表示切り替え:横長カードの構成を変えたい場合

現在の `index.html` は、横長カードから「美顔器Deep Boost」のみを外し、「飲むビタミンC」「クッションファンデーション」の2枚を表示する構成です。3枚すべて表示したい場合は `index_full.html` を `index.html` の代わりにアップロードしてください。

横長カード自体を丸ごと非表示にしたい場合は、`<style>` タグの一番下に以下の1行を追記してください(削除すれば表示に戻ります)。

```css
.ys-wide-list{ display:none; }
```

## 現在の実装内容

- **FV**: 告知画像を全幅表示。画像内の「クーポン獲得はこちら」ボタンの上に、実際にクリックできるリンクを透明で重ねています(設定済みのクーポンURLに遷移します)。
- **タイマー**: FV直下に表示。3日限定企画の**開始前は「開始まで」**、**開催中は「終了まで」**に自動で切り替わり、終了後は「終了」の表示になります。
- **紙吹雪演出**: FV画像の上に、ページ読み込み時+数秒おきに紙吹雪がバーストする演出。
- **商品一覧**:
  - 美容液2点(2列固定)+成分注釈(※1〜※3)
  - 定番アイテム12点(スマホ2列/PC3列)+美白注釈(※)+セールバナー+クーポンバナー(20%OFF)
  - 横長カード(1列・写真大きめ・割引バッジ付き) — `index.html`は2枚(飲むビタミンC/クッションファンデーション)、`index_full.html`は3枚(美顔器Deep Boostを含む)
- **ヘッダーロゴ**: タップでYunth公式楽天市場店トップページへ遷移します。
- スマホでの商品名・バッジの折り返しは、単語やカタカナ語の途中で切れないよう調整済みです。

## 設定済みの内容

- **クーポン取得URL**: 設定済みです。変更する場合は `index.html` 内 `<script>` タグの `COUPON_URL` を書き換えてください。
- **タイマー日時**: `CHANCE_START`(9/3 10:00)・`CHANCE_END`(9/3 23:59)に設定済みです。

## 実装上のご注意

- JavaScriptを使用しています(カウントダウン・紙吹雪演出)。JavaScriptが実行できない環境には設置できませんのでご留意ください。
- スマホ表示を基準に作成しており、600px以上でPC向けレイアウトに切り替わります。
- Google Fonts(Zen Kaku Gothic New / Josefin Sans)を外部読み込みしています。
- 商品画像はご提供いただいたブランド画像を使用し、リンク先は各商品の楽天市場ページに設定しています。差し替えたい場合は `images/product/` 内の同名ファイルを上書きしてください。
